# Personal Portfolio Website

A personal portfolio website developed using React, JavaScript,
and CSS to showcase my professional background, technical skills,
education, work experience, and projects.

## About the Project

This project was created to provide a structured and accessible
overview of my experience as a Software Engineer.

The portfolio highlights my background in software testing,
programming, databases, and data analytics.

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- Git & GitHub

## Features

- Professional profile and introduction
- Education and work experience sections
- Technical skills overview
- Academic and personal projects
- Contact information and professional links

## Getting Started

To run the project locally:

1. Clone the repository:

   git clone https://github.com/deaosmanaga/react-portfolio.git

2. Navigate to the project directory:

   cd react-portfolio

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev
